# Biblioteca de portadas HAIC

Las portadas usan formato 3:2, una composición legible en tarjetas pequeñas y el lenguaje visual de HAIC: azul marino, ámbar, cyan, iluminación editorial y datos integrados en el entorno. No contienen texto, logotipos ni interfaces ficticias.

## Casos de uso disponibles

| Portada | Caso de uso |
| --- | --- |
| `agricultura-precision` | Monitoreo de cultivos, riego y salud vegetal |
| `gestion-inteligente-agua` | Detección de fugas y administración responsable del agua |
| `triaje-salud-comunitaria` | Apoyo al triaje y planeación de recursos clínicos |
| `movilidad-inteligente` | Predicción de flujo y movilidad multimodal |
| `clasificacion-residuos` | Separación de residuos y economía circular |
| `energia-renovable` | Pronóstico y balance de energía renovable |
| `mantenimiento-predictivo` | Detección temprana de fallas en maquinaria |
| `monitoreo-ambiental` | Riesgo ambiental e incendios forestales |
| `lenguas-originarias` | Preservación y tecnología de voz para lenguas originarias |
| `proteccion-civil` | Alertas tempranas de inundación y deslizamiento |

Cada portada tiene una versión de `1200 × 800` para detalle y otra de `640 × 427` para tarjetas. Ambas están comprimidas en AVIF y `ResponsiveImage` selecciona automáticamente el tamaño apropiado.

## Prompt visual común

Las diez imágenes se generaron como ilustraciones editoriales 3D de realismo estilizado, con un único problema comunitario como foco, geometría clara, datos representados mediante luz y restricciones explícitas contra texto, marcas de agua, robots humanoides, cerebros luminosos y circuitos decorativos excesivos. Cada prompt cambió el escenario, el encuadre y la metáfora según el caso de uso.
