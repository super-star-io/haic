# Prompt para iniciar una funcionalidad

Trabaja en la plataforma HAIC siguiendo `harness/README.md` y los invariantes de `harness/context/invariants.md`.

Antes de editar la aplicación:

1. Examina el comportamiento y el código actual.
2. Crea la siguiente carpeta numerada en `harness/specs/`.
3. Completa `spec.md`, `plan.md` y `tasks.md` a partir de las plantillas.
4. Señala cualquier decisión de producto, seguridad o datos que requiera aprobación.
5. Implementa sólo el alcance aprobado.
6. Completa `verification.md` con resultados reales.

No publiques ni despliegues. No sustituyas cambios existentes ajenos al alcance. Toda afirmación de terminado debe estar respaldada por evidencia.
