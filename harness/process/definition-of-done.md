# Definición de terminado

Una especificación está terminada cuando:

- Todos los criterios de aceptación tienen evidencia.
- Lint y build terminan correctamente.
- Las pruebas automatizadas relevantes pasan.
- Los recorridos manuales críticos fueron ejecutados.
- Autenticación, autorización, validación y exposición de datos fueron revisadas cuando aplican.
- Las migraciones fueron probadas localmente y documentan recuperación.
- No se agregaron secretos ni datos personales a fixtures o logs.
- La experiencia fue revisada en escritorio y móvil cuando existe interfaz.
- Se respetan estados de carga, vacío, error y éxito.
- Contexto, ADR y documentación fueron actualizados si corresponde.
- No quedan tareas obligatorias abiertas.
- El cambio permanece local salvo autorización explícita para publicarlo.
