# Human-centered community HOME

## Objective

Reframe HAIC around people, learning and local impact so a new visitor can understand what HAIC is and how to participate without technical context.

## Requirements

- Lead with a human promise and a contribution-oriented call to action.
- Explain the HAIC loop in three steps: learn, build and create impact.
- Present projects by mission and ways to help before technical resources.
- Show only real team members and derived platform metrics; do not invent testimonials or impact.
- Make non-code roles, values and a first-contribution path visible.
- Preserve dynamic projects, embedded video, authentication and responsive behavior.
- Document the community's durable principles in `PHILOSOPHY.md`.

## Acceptance criteria

- A first-time visitor can identify HAIC's purpose and first action from the initial viewport.
- The HOME contains clear sections for process, people, participation roles, values and first contribution.
- Project cards describe ways to help in approachable language.
- All displayed counts are derived from current content or static facts present in the codebase.
- The production build, lint and automated tests pass.
