# Especificaciones

Cada cambio vive en una carpeta numerada:

```text
specs/
  001-nombre-corto/
    spec.md
    plan.md
    tasks.md
    verification.md
```

Los números son consecutivos y no se reutilizan. La carpeta conserva su nombre aunque el estado cambie. Copiar los archivos desde `templates/` y reemplazar todos los marcadores.
